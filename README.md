# Blogg Frontend
Detta projekt är en frontend-applikation för en enkel bloggplattform där användare kan skapa, läsa, uppdatera och ta bort sina egna blogginlägg. Projektet är en del av kursen Fördjupad Frontendutveckling hos Mittuniversitetet. 

## Funktioner
	•	Visa alla blogginlägg på en publik sida
	•	Visa de senaste inläggen på startsidan
	•	Registrering och inloggning för användare
	•	Skapa, redigera och ta bort egna inlägg
	•	Visa blogginlägg i detalj på en egen sida

## Teknologier
	•	React + TypeScript
	•	Zustand (state management)
	•	React Router
	•	CSS 
	•	Fetch API mot backend (Node.js + Hapi + MongoDB)
	•	Context API för autentisering (AuthContext)
